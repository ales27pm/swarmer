# Expo SDK 55 compatibility with local Xcode 26.3

The mobile app moves from Expo SDK 57 to SDK 55.0.31 so it can be built with
the installed Xcode 26.3 (17C529), on macOS 15.7.9. SDK 55 is the newest
Expo release whose published Xcode minimum is met by this host: Xcode 26.2+.
SDKs 56 and 57 require Xcode 26.4+.

Sources: [Expo compatibility matrix](https://docs.expo.dev/versions/v56.0.0/),
[Apple toolchains](https://developer.apple.com/xcode/system-requirements/),
[Apple submission requirements](https://developer.apple.com/news/upcoming-requirements/).
Xcode 26.3 includes iOS SDK 26.2 and meets the current Xcode 26 / iOS 26
upload minimum. This compatibility statement is separate from archive,
upload, processing and device-runtime evidence.

## Changes

- Align Expo modules, Router, React Native 0.83.10, React 19.2.0, Reanimated,
  Worklets and the Jest preset with Expo 55's bundled dependency matrix.
- Pin `expo-font` to 55.0.8: the unbounded peer of `expo-symbols` otherwise
  selected SDK 57 fonts and created duplicate native module versions.
- Use SDK 55's Contacts and Calendar package entry points, preserving
  authorization and permission checks. The regression tests assert the
  requested fields, date range and mapped output.
- Replace the SDK 57 `@Record` macro with SDK 55's `Record` protocol and
  `@Field` properties. Generation result field names and defaults remain
  unchanged, including explicit default and value initializers.
- Configure the iOS 18 deployment target through `expo-build-properties` so
  it reaches the generated native project and the Core ML/MLX/GGUF module.
- Preserve pinned native inference dependencies and the signed archive's
  rejection of Testing/XCTest dependencies. No model catalog or backend
  runtime changes are part of this migration.
- Reserve build `0.1.0 (20260913004000)` for `org.27pm.mongars`.
